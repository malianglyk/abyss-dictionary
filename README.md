# Abyss Lexicon: Card of the Abyss

> Roguelike 英文单词学习卡牌游戏 — 踏入深渊，以知识为剑。

## 🎮 游戏简介

《Abyss Lexicon》是一款将 Roguelike 卡牌玩法与英语单词学习相结合的单页 Web 游戏。

- **类型**：Roguelike 卡牌单词学习（英→中输入）
- **层数**：无限层，每层 15 个节点
- **词库**：SAT 机考阅读核心词汇 100 词
- **目标**：将全部 100 个单词转化为「精通」状态（3 星），征服深渊

## 🎯 核心机制

### 卡牌系统
- 每个单词是一张卡牌，分为 **🛡️ 防御** 和 **⚔️ 进攻** 两种类型
- 防御卡：答对获得护甲，抵挡怪物攻击
- 进攻卡：答对造成伤害，击杀怪物
- 伤害/护甲 = 1 + 卡牌星级

### 星星系统
- 每场战斗中正确使用的卡牌获得 +1 星（答错过的不加分）
- 3 星 = 精通，卡牌永久移出牌组
- 全部 100 词精通 = 胜利

### 战斗流程
1. 抽牌至 3 张手牌
2. 点击卡牌 → 输入中文释义 → 确认
3. 正确 → 应用效果（防御加甲/进攻伤害）
4. 错误 → 卡牌弃置（本场战斗内）
5. 手牌打光或手动结束回合 → 怪物阶段
6. 所有怪物死亡 → 战斗胜利 → 颁发星星 → 添加新卡

### 节点系统（每层 15 个）
| 类型 | 比例 | 说明 |
|------|------|------|
| ⚔️ 战斗 | 50% | 卡牌对战 |
| ❓ 事件 | 18% | 二选一抉择（11 种事件） |
| 🛒 商店 | 15% | 购买药水和能力 |
| 🛌 休息 | 10% | 恢复生命值 |
| 💧 记忆泉 | 7% | 复习已精通单词（回忆中文释义）；尚无精通词时随机卡牌 +1 星 |

### 商店系统
- **🧪 药水**（前 3 格）：一次性物品，存入背包，随时使用
- **🔮 能力**（后 3 格）：永久被动效果，价格更高
- 每种物品购买后即售罄
- 每次商店随机从大池中抽取 3+3 件

### 背包系统
- 最多携带 2 件药水
- 按 1/2 键或点击背包栏使用
- 非战斗状态下可使用

### 能力系统（永久被动）
- 10 种永久能力，从商店或事件获得
- 效果包括：额外抽牌、永久护甲、击杀回血、双倍伤害等
