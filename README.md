# 深渊词典：百房深渊

> Roguelike 英文单词学习游戏 — 踏入深渊，以知识为剑。

## 🎮 游戏简介

《深渊词典：百房深渊》是一款将 Roguelike 玩法与英语单词学习相结合的单页 Web 游戏。

- **类型**：Roguelike 单词学习（英→中输入）
- **层数**：固定 5 层，每层 20 个节点（共 100 个房间）
- **词库**：SAT 机考阅读核心词汇 100 词
- **目标**：将全部 100 个陌生单词转化为「精通」状态，击败第 5 层深渊领主

## 🎯 核心机制

### 单词状态机
- **未见** → 首次遭遇后进入「学习中」
- **学习中** → 累计答对 2 次晋升「复习中」
- **复习中** → 答对 2 次晋升「精通」，连续答错 2 次退回「学习中」
- **精通** → 永久移除怪物池，跨局保留
- **深渊回响** → 精通词在第 4~5 层有概率以精英形态乱入

### 渐进式提示
- 第 1 次答错：显示英文造句
- 第 2 次答错：显示中文首字提示
- 第 3 次答错：显示答案，强制跳过（不扣血、不计进度）

### 节点系统
| 类型 | 比例 | 说明 |
|------|------|------|
| ⚔️ 战斗 | 40% | 2~5 个单词的群怪战 |
| ❓ 事件 | 20% | 二选一抉择 |
| 🛒 商店 | 15% | 购买道具 |
| 🛌 休息 | 15% | 恢复生命值 |
| 💧 记忆泉 | 7% | 随机学习进度+1 |
| 💀 陷阱 | 3% | 损失生命值 |

## 🚀 快速开始

在线游玩：**[https://malianglyk.github.io/abyss-dictionary/](https://malianglyk.github.io/abyss-dictionary/)**

或本地运行：
```bash
git clone https://github.com/malianglyk/abyss-dictionary.git
cd abyss-dictionary
# 用浏览器直接打开 index.html
```

## 📚 词库选择

游戏启动前可在标题画面选择不同的词库：

- **SAT Core Vocabulary** — 100 个 SAT 阅读核心词汇（默认词库）
- **10S SAT 词汇-4** — 100 个 SAT 机考阅读词汇题词汇（来自 Flying Tiger 平台）
- **📝 Custom** — 使用内置编辑器自定义词库

词库数据存储在 `word_banks/` 目录下。可通过修改 JSON 文件添加更多词库，并在 `word_banks/manifest.json` 中注册。

## 🛠 技术栈

- 纯 HTML/CSS/JavaScript 单页应用
- 浏览器 LocalStorage 数据持久化
- GitHub Pages 部署

## 📖 跨局继承

仅「学识录」（已精通单词列表）跨局保留。精通单词在后续游戏中不再出现。
当学识录达到 100 词时解锁「永恒殿堂」全局通关画面。
